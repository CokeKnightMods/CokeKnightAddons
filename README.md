# CokeKnightAddons 0.17.0 optional assets

This versioned branch contains the 860 individual cosmetic packages used by CokeKnightAddons.
The mod downloads only selected packages and required shared resources. Package filenames
include their SHA-256 prefix; the client verifies their full digest before activation.

Install the mod from the main release, not by cloning or downloading this entire branch.
The release manifest records the exact immutable commit URL and complete dependencies.
These are existing project assets; this repository does not grant a new license to third-party content.
